Fix `__getattr__` not being accessible from Python by looking it up on the type, e.g. `type(obj).__getattr__(obj, "attr")`. PyO3 now generates a `__getattr__` entry in the type's `tp_methods` (with a checked receiver type conversion, raising `TypeError` for a wrong receiver type) so it can be looked up and called from Python, matching the behaviour of dunder methods that have CPython slot wrappers.
