Fix inconsistent exception types when converting negative Python `int`s to unsigned Rust types; these now consistently raise `ValueError` on all Python versions (matching newer CPython APIs such as `PyLong_AsUInt64`), instead of raising `OverflowError` on Python 3.12 and earlier. This also fixes `u128` conversion silently wrapping negative values when building with the `abi3` feature for Python earlier than 3.15.
