Add `PYO3_BASE_PYTHON` environment variable. Build frontends that point `PYO3_PYTHON` at a temporary virtualenv which is recreated with a new path on every build (e.g. `pip install .` with PEP 517 build isolation) can set `PYO3_BASE_PYTHON` to the path of the underlying base interpreter (e.g. the value of `sys._base_executable`). PyO3 then tracks that stable path for rebuild detection instead of `PYO3_PYTHON`, so the `pyo3-*` crates are no longer needlessly recompiled on every build. `PYO3_BASE_PYTHON` does not affect which interpreter is used. If set to a path that is not a file, it is ignored with a warning.
