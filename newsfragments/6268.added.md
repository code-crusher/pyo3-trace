Add `pyo3::allocator::PyMemAllocator`, a `GlobalAlloc` implementation backed by the Python raw memory allocator (`PyMem_Raw*`). It is opt-in via `#[global_allocator]`, is thread-safe and does not require the calling thread to be attached to the interpreter, and makes Rust-side allocations visible to `tracemalloc`. This is primarily aimed at improving allocation scalability for extension modules on the free-threaded build of CPython. The raw allocator functions are also now exposed as `pyo3::ffi::PyMem_RawMalloc`/`PyMem_RawCalloc`/`PyMem_RawRealloc`/`PyMem_RawFree` on limited API builds targeting Python 3.13 and newer.
